LLM Validation · Bias Auditing01

LLM Claims Triage Systems Validation

Second-line model risk governance & bias auditing harness

An independent MRM validation harness for auditing NLP- and LLM-driven claims triage engines. It evaluates generative outputs for non-deterministic drift, demographic disparity, and decision alignment — bringing automated fairness auditing and explainability controls to high-consequence workflows.

  • Detects output drift in non-deterministic LLM decisions
  • Quantifies demographic disparity with Fairlearn metrics
  • Maps findings to NIST AI RMF, NAIC and SR 11-7

Data Governance · Lineage03

Socrata–PLUTO QA Audit Gate

Automated data quality & lineage validation for public-sector ML pipelines

A data governance gate that enforces upstream integrity for AI/ML systems consuming open data (Socrata Open Data API / NYC PLUTO). It automates pre-ingestion schema validation, completeness checks, and distribution drift detection to block tainted features before any model consumes them.

  • Pre-ingestion schema and data-contract enforcement
  • Blocks drifted or incomplete features upstream
  • Immutable JSONL audit trail for data provenance

Operational Risk · Impact04

Operations Impact Analysis

Algorithmic downstream impact & operational risk governance framework

A framework that looks past standalone model metrics to measure what model failures cost the business. It quantifies operational disruption, SLA degradation and organizational risk from model failures and edge cases, formalizing post-deployment impact assessment.

  • Scenario stress-testing of automated decision workflows
  • Sensitivity and bottleneck analysis for SLA risk
  • YAML/JSON operational risk registries for executives
